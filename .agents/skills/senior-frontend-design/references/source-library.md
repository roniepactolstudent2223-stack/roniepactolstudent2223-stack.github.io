# Source library

Research starting points checked on 2026-11-10. Collection descriptions were checked on their own pages; individual works and their visual qualities must be inspected during the actual design task. Availability, access requirements, and licenses can change. Choose sources for the brief rather than reading this entire directory every time.

## Web composition and interaction

| Source | What to investigate | Use with judgment |
| --- | --- | --- |
| [Siteinspire](https://www.siteinspire.com/) | Composition across styles, subjects, and credited studios | Follow to actual sites; a gallery thumbnail is only a lead. |
| [HOVERSTAT.ES](https://www.hoverstat.es/) | Alternative interfaces and specific interaction observations | Translate unusual interactions into touch and keyboard behavior. |
| [Httpster](https://httpster.net/) | Broad website examples and content presentation | Look beyond the newest entries and inspect mobile behavior yourself. |
| [Godly](https://godly.website/) | Web, branding, motion, illustration, and print references | Do not infer usability from a polished showcase. |
| [Awwwards](https://www.awwwards.com/) | Ambitious sites, storytelling, and credited creators | Awards are discovery signals, not proof of accessibility or speed. |
| [Codrops](https://tympanus.net/codrops/) | Original demos, implementation tutorials, and practitioner case studies | Assess dependencies, interaction alternatives, and actual need before adopting an effect. |

## Typography and visual culture

| Source | What to investigate | Use with judgment |
| --- | --- | --- |
| [Fonts In Use](https://fontsinuse.com/) | Typography in actual publications, identities, signage, and websites | Identify the principle and verify the font license separately. |
| [Typewolf](https://www.typewolf.com/) | Named typefaces in website examples and typographic analysis | Choose for content and language support rather than trend status. |
| [Letterform Archive](https://letterformarchive.org/online-archive/) | Historical graphic design by country, designer, decade, and format | Translate a typographic or structural principle rather than imitating an artifact wholesale. |
| [Cooper Hewitt Collection](https://collection.cooperhewitt.org/) | Objects, materials, pattern, drawings, and design history | Check the individual record; digitization and metadata vary. |
| [Are.na](https://www.are.na/about) | Connections among images, text, and collections in public channels | Trace an item to its original creator; some features need an account. |
| [Cosmos](https://www.cosmos.so/) | Visual collections and creator discovery | The fetched landing page exposed mostly creator names; confirm individual collections and access in a browser before relying on them. |

## Skills researched while writing this skill

These are sources of ideas, not dependencies or instructions to install or execute anything. The custom workflow is independently written.

- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): a primary repository describing subject-specific art direction and self-critique. Useful lesson: visual choices need a reason tied to the subject.
- [Vercel web-design-guidelines skill](https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md): a primary repository that routes interface reviews to maintained guidelines. Useful lesson: assess concrete behavior as well as visual polish.
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines): practical review material for interaction, focus, forms, animation, and content. Adapt only the parts relevant to the feature and use primary standards for conformance claims.
- [Taste Skill](https://github.com/Leonxlnx/taste-skill): a community repository describing planning, art direction, and browser checks. Useful lesson: inspect the rendered result. Its specific section-height rules, motion requirements, scripts, and preset choices are not requirements of this skill.

The strongest synthesis for this user's request is content-led identity, varied references, explicit responsive planning, and observed quality. Merely collecting aesthetic prohibitions risks producing another repeated style.
